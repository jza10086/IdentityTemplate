# 阿瓦隆人工验收

目标：通过编辑器启动独立游戏进程，实际点击验证私密身份、操作界面与结算。自动化按钮回调测试不等同于鼠标命中、多窗口焦点或视觉验收。

## 准备五个窗口

1. 确认编辑器项目为 GodotParty。停止当前运行的游戏，再打开编辑器的“运行多个实例／自定义运行实例”设置，启用 5 个实例。
2. 为各实例配置独立运行参数。下面是完整自定义参数，开头 `--` 用于分隔 Godot 参数和游戏参数。若编辑器提供专门的用户参数栏，只填后面的 `--party-...` 部分。

| 实例 | 参数 |
| --- | --- |
| 房主 | `-- --party-profile=identity_manual_host --party-host --party-port=18425 --party-main=godot_party_default_maingame_minigame_playlist --party-mini=gp_avalon` |
| 客户端 1 | `-- --party-profile=identity_manual_c1 --party-join=127.0.0.1 --party-port=18425` |
| 客户端 2 | `-- --party-profile=identity_manual_c2 --party-join=127.0.0.1 --party-port=18425` |
| 客户端 3 | `-- --party-profile=identity_manual_c3 --party-join=127.0.0.1 --party-port=18425` |
| 客户端 4 | `-- --party-profile=identity_manual_c4 --party-join=127.0.0.1 --party-port=18425` |

3. F5 运行正式主场景。如果客户端启动早于房主而连接失败，等房主大厅出现后，在该客户端直连 `127.0.0.1:18425`。每个窗口必须使用不同 profile；不要复制同一个玩家资料槽。
4. 房主大游戏配置设总局数 1、顺序、允许重复、间隔 0。小游戏池只选“阿瓦隆”。确认大厅有五名不同玩家，所有客户端准备后开始。
5. 所有视觉验收仅使用 1920×1080。可在各窗口设置不同昵称以便区分。

## 阿瓦隆：建议走三次成功后刺杀路线

使用上述阿瓦隆房间与独立 profile。

| 步骤 | 操作 | 应看到的结果 |
| --- | --- | --- |
| 阿瓦隆序言与字幕 | 开局观看三句序言，再观察阶段切换和队伍票提交刷新 | 序言逐行完整播放，行间停顿短；序言结束后出现行动控件，空格可跳过；字幕不因状态刷新突然消失，新提示在旧文字淡出后出现；等待队长显示真实名称 |
| 开局与身份 | 开局查看左上、左下角及各人物卡 | 直接进入 1/5 回合、队长提名阶段，无身份确认或私密查阅；左下只显示身份大标题与简介；梅林看到邪恶玩家的“邪恶阵营”标记，刺客和爪牙看到“邪恶同伴”，忠臣只知道自己的身份；具体角色终局才揭晓 |
| 身份百科 | 点击右下角“身份百科”，查看并关闭窗口；在投票页重复 | 四种身份简介完整，和左下角完全一致；不显示本局身份分配；关闭后保持原阶段及未提交的选择；阶段刷新后仍能正常关闭 |
| 队长组队 | 队长点选、取消再重选人物卡，选满后确认 | 只有队长能选人，可选自己；没选满不能确认；多选高亮清楚；非队长只能等待或查看自己的身份 |
| 队伍投票 | 在主界面直接选赞成／反对，再确认 | 无“确认是我”步骤；人物卡实时显示未投票／已投票，身份标记一直可见；未选择时不能确认；未全部提交时不公开票面；全员提交后逐人公开赞成或反对，3 秒后自动继续 |
| 任务投票 | 全体赞成队伍；任务成员秘密选成功；非队员等待 | 好人没有“任务失败”选项；邪恶有两个选项；任务只公开成功／失败数量，不显示投票人，也不泄漏其他人的提交顺序 |
| 等待与重复远征 | 全员完成选择后等待自动推进，重复直到三次成功 | 中央分别提示等待队长、全体玩家、远征队员或刺客；不暴露刺客姓名和个人任务牌提交状态；结果显示 3 秒后自动继续，无需房主点击；队长轮换、任务人数和进度更新，无上一轮选项残留 |
| 刺杀 | 刺客选一个忠臣，再确认 | 只有刺客能操作；未选目标不能确认；目标列表不标出梅林；刺杀忠臣后好人胜利；另测刺杀梅林应邪恶胜利 |
| 结算 | 等待总成绩 | 所有窗口胜负、排名、积分相同；完成 1/1 局，只结算一次 |

补测：连续五次否决队伍应邪恶胜利；7–8 人第 4 次任务需两张失败牌才失败。

## 两种玩法共用的检查

- 人数：只留 4 人时狼人杀可开局；改成阿瓦隆后所有客户端提示 5–8 人且不能开局。增加第 5 人后恢复。若池中还选其他小游戏，人数必须继续取交集。
- 私密页：打开某个玩家的身份时，让其他玩家提交操作；本机身份不能变成别人，也不能在公共页短暂闪现。缩放窗口和切换焦点后继续检查。
- 连续两局：总局数改 2，只选身份派对。第二局座次正确，身份重新分配，投票／选择／查验记录重置；总积分累加一次。身份可能随机重复，不能仅凭相同身份判定未重置。
- 主动退出：玩家在游戏内确认离开后，本局取消、无胜负积分，约 3 秒后轮换暂停，房主可重试或结束。
- 断线：关掉一个参赛客户端，预期同上；房主关闭则会话结束，不尝试迁移主机。
- 超时：房间设置时间上限为最小值 5 分钟，留一人不操作；到时应取消而不是判其余玩家获胜。
- 视觉与输入：私密遮罩完全覆盖，文字不截断，人物卡不遮按钮；单击只触发一次，双击不跨阶段；Esc 弹窗的继续／退出行为明确。
- 计分：胜者并列第 1，败者名次为胜者人数 + 1；积分为“参赛人数 − 名次 + 1”。例如 5 人阿瓦隆好人胜利时，3 名好人各 5 分、2 名邪恶各 2 分；取消局不加分。

记录问题时提供：玩法、人数、窗口昵称／身份、阶段、操作步骤、预期／实际结果和截图。私密问题尽量同时提供出问题窗口与另一个窗口的画面。

完成后停掉测试实例，将编辑器实例数和自定义参数恢复到测试前状态。测试 profile 与原玩家资料分开，无需删除原存档。

## 自动化入口和边界

旧身份聚会自动化入口已退役归档，不再运行或维护。后续验证按当前改动在项目根目录 tmp/test/ 建立最小检查；本文件中的人工多实例流程继续用于真实交互验收。
