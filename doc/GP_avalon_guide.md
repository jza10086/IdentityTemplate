# 阿瓦隆（身份派对包）

由 [IdentityTemplate](https://github.com/jza10086/IdentityTemplate) 接入的 API 4 原版协议小游戏包，包含狼人杀和阿瓦隆。上游检出版本：`2e4eb66d1e18bf6c09e6f95ab1a4da794c6b61bf`；完整克隆保留在项目 `tmp/IdentityTemplate/`。游戏内使用本包资源，不依赖临时克隆目录。

## 在大厅启动

选择 `GP_minigame_playlist`，在小游戏池勾选“阿瓦隆”。当前正式配置仅允许阿瓦隆，5–10 人；狼人杀源码保留，尚未开放。大游戏总局数设为 1 可以单独测试。大厅人数与实际子局参赛人数分别检查。轮换大厅提供语音，进入本小游戏后关闭，游戏内讨论仍使用玩家自行选择的语音方式。

## 角色配置

大厅的阿瓦隆设置中选择“基础配置”或“自定义角色配置”。基础配置保留梅林、刺客，其余按阵营配额补忠臣和爪牙。自定义配置可分别启用派西维尔、莫甘娜、莫德雷德、奥伯伦，每个特殊角色最多一名；梅林和刺客仍固定存在。特殊角色替换本阵营的普通角色，不额外增加人数。房主用私有随机源分配全部身份，不按大厅席位指定身份。

| 人数 | 正义 / 邪恶 | 五次远征人数 |
| --- | --- | --- |
| 5 | 3 / 2 | 2、3、2、3、3 |
| 6 | 4 / 2 | 2、3、4、3、4 |
| 7 | 4 / 3 | 2、3、3、4、4 |
| 8 | 5 / 3 | 3、4、4、5、5 |
| 9 | 6 / 3 | 3、4、4、5、5 |
| 10 | 6 / 4 | 3、4、4、5、5 |

7–10 人第四次远征需要两张失败票才失败，其余远征一张即可。自定义邪恶角色（含刺客）不能超过邪恶配额；5 人启用派西维尔时还须启用莫甘娜或莫德雷德。大厅自动收窄允许开局人数，例如同时启用三个新增邪恶角色时只允许 10 人。所有规则组合和实际发牌共用 `definition.gd` 的配置定义。经典规则参考：[The Resistance: Avalon 规则书](https://www.rulespal.com/resistance-avalon/rulebook)。

| 角色 | 可见信息 |
| --- | --- |
| 梅林 | 除莫德雷德以外的邪恶玩家，包括奥伯伦；不显示具体角色 |
| 派西维尔 | 梅林与莫甘娜都标为“梅林候选”，不能区分 |
| 刺客、爪牙、莫甘娜、莫德雷德 | 互相识别为邪恶同伴，不认识奥伯伦 |
| 奥伯伦、忠臣 | 不知道其他人的身份或阵营 |

这些信息只发送给对应玩家。未启用莫甘娜时，派西维尔只有梅林这一名候选；奥伯伦仍属邪恶阵营，可提交失败票并参与邪恶胜负。刺客可盲选身份未知的奥伯伦，结果视为未刺中梅林，不通过目标校验泄露奥伯伦身份。

## 规则与界面

- 狼人杀：4–6 人配置 1 狼、1 预言家，其余村民；7–8 人配置 2 狼、1 预言家，其余村民。4 人首夜平安。查看身份后进入夜间行动、白天讨论和放逐投票；好人消灭全部狼人获胜，狼人达到人数优势获胜。
- 阿瓦隆：支持上述 5–10 人人数表、八种身份、队长提名、公开队伍投票、匿名任务投票、五次拒绝队伍及终局刺杀规则。三次任务成功后仍须通过刺杀结算。
- 阿瓦隆开局直接进入队长提名，无身份确认或私密查阅。左上角显示远征回合（1–5）和当前阶段；左下角常驻本人身份标题与简介；右下角“身份百科”展示八种身份，和左下角共用简介。特殊身份按上表在人物卡上显示可见信息；不会提前显示他人的具体角色。投票与刺杀直接在主界面操作，不遮挡人物卡；未提交的选项仍只留在本机。
- 保留月夜背景、环形座次、任务牌和字幕。阿瓦隆全员完成当前行动后自动结算，结果展示 3 秒后由房主自动推进，无手动继续按钮。中央按阶段提示等待队长、全体玩家、远征队员或刺客；队伍投票时人物卡显示“未投票／已投票”，结果揭晓前不显示票面，任务牌的个人提交状态仍不公开。狼人杀保留原私密身份页与确认流程及手动推进。
- 阿瓦隆界面文字放大约 12%，人物卡与底部面板同步扩展。开局逐行播放三句序言，约 10 秒、行间空隙 0.1 秒；序言期间本机暂不显示行动控件，空格可主动跳过。独立字幕层保留当前行完整淡入／停留／淡出，新阶段只更新待播提示，频繁刷新合并为最新状态；等待队长时显示“等待队长「名称」选择队员”。
- 牌桌布局在 `scenes/avalon.tscn`，座位外观在 `scenes/avalon_player_card.tscn`，按座位绑定当前玩家可见的数据。九、十人使用顶部与两侧三层座位，本人固定下方；观战者看到完整牌桌。新增角色图标为包内原创 SVG，登记于 `ASSET_LICENSES.md`。
- 讨论使用玩家自行选择的语音方式；本包不新增聊天或语音系统。本地设置“减少动态效果”只影响本机。

## 联机与结果

房主使用私有随机源分配身份，持有完整规则状态；客户端仅发送逻辑操作及阶段编号。框架认证的玩家 ID 映射为座次，客户端不能指定操作者。公共事实变化广播，私人身份与笔记只定向发给所有者；历史只追加，公共与私人消息按版本合并后呈现。观战者只收到公开信息，结束后按上游规则揭晓身份。观战房主仍可推进公开阶段。

阿瓦隆使用参赛者的大厅昵称和原版协议分配的房间颜色。每张玩家卡片以该颜色作为边框，背景使用同色的深色调。

正常终局列出每位参赛者的阵营、胜负与本局名次。胜方并列第一，败方并列第 `max(4, 胜方人数 + 1)` 名，所有新增角色按所属阵营结算。原版轮换大游戏按「参赛人数 − 本局名次」累计积分。终局展示 8 秒后进入协议结算页，房主也可点击「返回大游戏结算」提前进入；协议等待所有客户端挂载结果并倒计时后提交。框架确认回合提交后恢复大游戏。

参赛者退出、断线或达到时间上限会取消本局，3 秒后交回大游戏。取消局不计分，轮换大游戏等待重试或结束。
