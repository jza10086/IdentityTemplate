# 月隐镇 · Identity Party

一套可扩展的 2D 身份推理游戏项目。第一章是 **4–8 人轻量版狼人杀**，有真正的局域网联机，也有共用一台设备的同屏传递模式。

## 立即运行

1. 安装 Godot 4.x，推荐 **Godot 4.7.2**（此版本已实测）。
2. 在 Godot 项目管理器导入本目录的 `project.godot`。
3. 按 F6 可运行主场景，按 F5 运行整个项目。
4. 不需要插件、账号、素材下载或外部后端。中文字体已随项目提供。

也可使用命令行：

```sh
godot --path /path/to/IdentityParty
```

交付为源项目，未包含各平台的预编译可执行文件。可使用 Godot 对应版本的官方导出模板导出 Windows、macOS 或 Linux 桌面版本；没有完成移动端或 Web 导出验证。

## 两种开局方式

### 局域网联机

- 每位玩家在自己的电脑上启动项目，连接同一个局域网。
- 一人选择“创建房间”，填写昵称和端口（默认 `24567`，UDP）。
- 等候室显示房主的局域网 IP。其他玩家选“加入房间”，输入该 IP 和相同端口。
- 房主默认已准备；其他玩家点击“我准备好了”。4–8 人全部准备后，房主开始游戏。
- 每人只在自己的设备上查看身份、夜间行动和查验记录。白天由房主推进讨论和投票。
- 同一台电脑测试多个窗口时，客户端可使用 `127.0.0.1`。

自动显示的 IP 是本机发现的一个私有地址；多网卡、VPN 或虚拟机环境下可能需选择正确的局域网地址。连接失败时检查同网段、IP、端口与系统防火墙对该 Godot 应用/导出程序的 UDP 放行情况。项目不会自动更改系统、防火墙或路由器设置。

### 同屏传递

- 选“同屏传递 · 开始一局”，设置 4–8 人和各自昵称。
- 屏幕先显示“请将屏幕交给某某”，本人确认后才显示秘密。
- 每次确认身份、夜间行动和投票之后，自动盖住上一人的信息并交接下一人。
- 白天展示公共画面。预言家可使用“私密查阅身份 / 记录”，选自己，再在遮挡页确认查看；看完必须收起秘密再交回设备。
- 同屏模式依赖参与者遵守交接约定，不是每个人单独登录的安全系统。

发言请使用面对面交流或你们已有的语音工具。项目没有语音、文字聊天或 AI 玩家。

## 第一版规则

| 人数 | 狼人 | 预言家 | 村民 | 首夜 |
|---|---:|---:|---:|---|
| 4 | 1 | 1 | 2 | 平安夜：仍然选目标和查验，但不造成死亡 |
| 5 | 1 | 1 | 3 | 正常 |
| 6 | 1 | 1 | 4 | 正常 |
| 7 | 2 | 1 | 4 | 正常 |
| 8 | 2 | 1 | 5 | 正常 |

4 人属于快速体验规则，推理空间较小；推荐 6–8 人。以上预设是本项目的简化规则，不宣称赛事级平衡。

### 流程

秘密身份确认 → 夜间行动 → 天亮公布离场者 → 讨论 → 秘密投票 → 公布结果 → 下一夜或终局。

- **狼人**：知道其他狼人的身份；每夜选择一名存活的非狼人目标。多狼选择不同时，最高票目标被袭击；最高票并列时取座次最靠前者。不允许自刀或袭击队友。
- **预言家**：每夜查验一个其他存活玩家，获知“狼人”或“好人”阵营；结果只保存在自己的私密记录中。结果在夜晚结算后可查看。同夜被袭击仍会完成查验，但离场后不能发言或投票。
- **村民**：夜间确认休息；依靠白天发言和投票找出狼人。
- **投票**：每位存活玩家一票，可弃票，不允许投自己。唯一最高票玩家出局。平票或全员弃票时无人出局。
- **胜负**：狼人全灭则好人获胜；存活狼人数量不少于存活好人时狼人获胜。每次死亡结算后检查。
- **信息公开**：离场者身份不立即公开；终局统一揭示所有身份。提交后不能修改行动或投票。
- **阶段推进**：夜间/身份/投票等待所有应行动者完成；讨论没有倒计时，由房主或同屏持机人主动推进。

没有女巫、猎人、警长、遗言、观战加入、断线重连、房主迁移或存档恢复。任何已入席客户端在对局中断线，本局取消，其他人返回等候室并重新准备；房主断线则客户端退回大厅。开始后的新玩家被拒绝加入，终局后需房主先返回等候室。

## 架构与扩展

```
scenes/main.tscn                  单一入口场景
scripts/core/game_catalog.gd      游戏注册表 / 规则实例工厂
scripts/core/werewolf_rules.gd    纯规则，无节点、输入、网络依赖
scripts/session/game_session.gd  本地会话 / ENet 连接 / 房主权威 RPC
scripts/ui/main.gd               2D 界面与遮挡交接
assets/art/                     原创 SVG 背景与三种角色卡
assets/fonts/                   离线中文字体及许可证
```

`GameCatalog` 目前只注册 `werewolf`。添加新身份推理玩法时，在工厂中注册规则实现；规则对象提供 `setup(players)`、`submit(player_id, action, target)`、`advance()`、`pending_player_ids()`、`public_view(viewer_id)` 等边界。会话负责参与者、传输和派发，UI 消费经过裁剪的视图。新游戏仍需增加对应的动作合法集、阶段呈现和说明；不是把未实现的玩法放进菜单。

### 权威与隐私边界

- 房主持有完整规则状态；客户端只发行动意图，服务端使用 RPC 实际发送者 ID 鉴权，不信任客户端指定玩家身份。
- 每人单独生成并发送 `public_view`，没有广播完整身份或夜间动作字典。只有狼人收到狼队友列表，只有预言家收到自己的查验记录。
- UI 从不在公共热座页展示私密记录；交接默认遮挡。
- 这是可信朋友间的局域网原型。ENet 通道未配置加密；房主进程拥有全量身份，不能防止房主读内存作弊。未做公网服务、反作弊或对抗性安全审计。
- 加入/操作/名称/人数/准备状态/目标/重复提交由权威端验证。连接超时、重名、房间满和晚加入有中文错误提示。

Godot 官方网络说明：https://docs.godotengine.org/en/stable/tutorials/networking/high_level_multiplayer.html

## 验证与测试

```sh
godot --headless --path . --script tests/test_rules.gd
godot --headless --path . --script tests/test_session.gd
godot --headless --path . --script tests/test_ui.gd
GODOT_BIN=/absolute/path/to/godot python3 tests/run_network_smoke.py
```

实际验证包括：4–8 人预设、170 场完整规则模拟、私密快照与深拷贝、无效/重复/死亡后操作拒绝、白天平票/弃票、狼人目标并列、4 人首夜平安、双方胜利、再开局、热座交接遮挡、退出确认及取消。

网络测试使用独立 Godot 进程和真实 ENet 回环连接：4 人完整对局，以及 8 人房间/第 9 人拒绝、重名/无效名称、未准备开局拒绝、晚加入拒绝、客户端掉线中止、房主掉线提示。回环联机通过不等于已在任意用户路由器/防火墙环境实测。

`tests/capture_screens.gd` 与 `tests/capture_lan.gd` 用真实 Godot 渲染器保存 UI 截图，需有图形显示环境。`CAPTURE_DIR` 可指定截图目录。测试脚本不会在正常游戏运行时执行。

## 两套完整美术

首次启动默认保留「月夜原版」。大厅右上角的「风格」按钮可随时在「月夜原版」与「几何剧场」之间切换；选择保存在本机 `user://presentation.cfg`，不会修改对局或发送给其他玩家。

「几何剧场」使用独立原创 SVG：奶油色日景、藏蓝色夜景、珊瑚色强调、几何人物与面具、粗体无衬线标题及直角卡片。覆盖大厅、同屏/联机设置、规则、交接遮挡、身份卡、玩家列表、夜间行动、投票和终局。夜色只由公开阶段决定；公共座位头像只由座次决定，绝不按秘密身份配图。

测试几何版完整热座流程：

```sh
IDENTITY_STYLE=geometry godot --headless --path . --script tests/test_ui.gd
godot --headless --path . --script tests/test_geometry.gd
IDENTITY_STYLE=geometry CAPTURE_DIR=/tmp/geometry-captures godot --path . --script tests/capture_screens.gd
```
