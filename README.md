# 月隐镇 · Identity Party

**4–8 人狼人杀派对小游戏**，回归月夜藏蓝 / 金色与原版插画。只保留游戏页面，没有主界面、大厅、房间设置、风格切换或独立规则菜单。

新增 **5–8 人阿瓦隆** 独立小游戏：打开 `scenes/avalon.tscn` 按 F6，直接进入 8 人预览；F5 默认狼人杀保持不变。基础梅林 / 刺客规则、任务人数、多人保密与宿主接入详见 [AVALON.md](AVALON.md)。两种游戏均无新增主菜单或大厅。

## 直接预览

使用 Godot **4.7.2** 导入 `project.godot`，F5 直接进入 **8 人同屏传递的回合开始页**。点击“开始本局，分发身份”后依次传递设备。无需账号、插件或外部后端。源项目不包含各平台可执行文件，也未验证移动端 / Web 导出。

```sh
godot --path /path/to/IdentityParty
```

画面四周为玩家卡片，靠边保留 20 个逻辑像素安全间距。中间只显示无边框的当前回合字幕，不再有四角标题、调试 / 状态文字或页脚。操作与确认集中于底部自己的卡片旁；身份与私密记录在明确进入的独立不透明隐私视图内显示。8 人按上 3 / 左 2 / 右 2 / 下 1 分布，底部唯一座位始终是当前查看者（标记“你”），包括已离场的自己。4–7 人隐藏多余位置，仍保留底部自己与两侧座位，不回退成矩形网格或侧栏。同屏私密回合随交接把当前玩家转到底部；公共阶段恢复初始查看者，私密查阅结束也恢复公共座位。联网按会话中的真实玩家 ID 定位，不假定连续编号。四周默认统一中性人物画像，绝不按隐藏身份配图；仅终局公开所有角色。

- 流程：回合开始 → 私密交接 / 身份揭晓 → 夜间行动 → 天亮 → 讨论 → 投票 → 投票结果 → 下一夜 / 终局。
- 选择行动目标：点击他人整张卡片（头像、名字和边缘均可），高亮选择后再在底部确认，单击不会立即提交。投票可弃票；自己、离场者及不合法夜间目标不可选，交接遮挡页没有可选目标。
- 同屏每次换人先遮挡秘密。讨论时可私密查阅自己的身份与查验记录，使用后收起。
- Escape 先确认退出，随后通知宿主退出。独立预览保留“再来一局”，不返回已删除菜单。
- 发言使用面对面交流或已有语音工具。本项目没有语音、聊天或 AI 玩家。

## 字幕节奏与辅助操作

天亮字幕按“天亮了，请睁眼” → “昨晚” → 实际离场者“某某遭到了狼人的毒手”或“一切平安”逐句播放。每句淡入 0.9 秒、停留 1.8 秒、淡出 0.9 秒、留白 0.35 秒；最后一句淡入后保持可读，等待玩家主动推进。字幕仅使用会话已公开结果，不读取隐藏角色。相同阶段的网络刷新、目标选择和视图重建不重播；阶段 / 回合 / 新局变化会取消旧序列并重新开始。

空格可跳到当前序列最后一句，不提交行动、不推进游戏（按钮拥有键盘焦点时保留标准按钮操作）。宿主可设置 `game.reduced_motion = true`，按同样时序直接换句而不做透明度动画。Escape 保留退出确认，无常驻顶部按钮。

## 接入派对框架

这是清晰的接入边界，不是已经完成了某个未提供的派对框架集成。

```gdscript
var game = preload("res://scenes/main.tscn").instantiate()
game.standalone_preview = false  # 加入场景前设置，避免启动默认预览
add_child(game)
game.finished.connect(_on_minigame_finished)  # Dictionary，终局公开结果，仅发一次
game.exit_requested.connect(_on_minigame_exit) # 无参，宿主卸载小游戏或切换场景
game.start_game(["青禾", "晚星", "听雨", "拾光"], 1)
```

`start_game(roster: Array, local_player_id: int = 1)` 接受 **4–8 个唯一昵称字符串**，按顺序映射为座位 ID 1..N。`local_player_id` 只选择首个同屏查看者，之后自动轮流交接；它不是登录身份、网络 ID 或客户端鉴权。身份由本地规则随机分配，不接受外部指定秘密角色。可在加入场景前调用，启动会延迟到 `_ready` 后。绑定外部会话后不可调用此方法替换宿主会话；新局由宿主管理。无效人数 / 重名 / 初始座位会被拒绝，不改变进行中的本地对局。

如果宿主已使用本项目的 `GameSession` 完成联网与开局，可调用 `game.bind_session(existing_session)`。UI 订阅该会话裁剪后的 `view`、通过它提交行动；外部会话生命周期由宿主管理。绑定不会自动加入房间、设置身份或重写网络协议。各端仍须保持 ENet RPC 节点路径一致。非游戏等待状态只显示中央等待提示，不出现大厅操作。退出只发 `exit_requested`，不会关闭或重置宿主拥有的外部会话 / 网络 peer；由宿主决定清理和之后去哪。只有独立预览自建的会话会自行关闭。

`finished(result)` 在终局首次出现时发送公开快照；界面留在终局供回看。宿主可随时卸载节点。独立预览再开局会重置该通知。自定义任意框架的网络 ID / 快照协议需要宿主适配，当前不声称通用即插即用。

## 第一版规则

| 人数 | 狼人 | 预言家 | 村民 | 首夜 |
|---|---:|---:|---:|---|
| 4 | 1 | 1 | 2 | 平安夜：仍然选目标和查验，但不造成死亡 |
| 5 | 1 | 1 | 3 | 正常 |
| 6 | 1 | 1 | 4 | 正常 |
| 7 | 2 | 1 | 4 | 正常 |
| 8 | 2 | 1 | 5 | 正常 |

4 人属于快速体验规则，推理空间较小；推荐 6–8 人。以上预设是本项目的简化规则，不宣称赛事级平衡。

### 流程

秘密身份确认 → 夜间行动 → 天亮公布离场者 → 讨论 → 秘密投票 → 公布结果 → 下一夜或终局。

- **狼人**：知道其他狼人的身份；每夜选择一名存活的非狼人目标。多狼选择不同时，最高票目标被袭击；最高票并列时取座次最靠前者。不允许自刀或袭击队友。
- **预言家**：每夜查验一个其他存活玩家，获知“狼人”或“好人”阵营；结果只保存在自己的私密记录中。结果在夜晚结算后可查看。同夜被袭击仍会完成查验，但离场后不能发言或投票。
- **村民**：夜间确认休息；依靠白天发言和投票找出狼人。
- **投票**：每位存活玩家一票，可弃票，不允许投自己。唯一最高票玩家出局。平票或全员弃票时无人出局。
- **胜负**：狼人全灭则好人获胜；存活狼人数量不少于存活好人时狼人获胜。每次死亡结算后检查。
- **信息公开**：离场者身份不立即公开；终局统一揭示所有身份。提交后不能修改行动或投票。
- **阶段推进**：夜间/身份/投票等待所有应行动者完成；讨论没有倒计时，由房主或同屏持机人主动推进。

没有女巫、猎人、警长、遗言、观战加入、断线重连、房主迁移或存档恢复。保留的 ENet 会话层在掉线时中止本局，回到会话的等待状态；UI 不再提供大厅或网络设置，派对宿主负责处理下一步。

## 结构与隐私

- `scripts/core/werewolf_rules.gd`：纯规则、合法行动、胜负与私密快照。
- `scripts/session/game_session.gd`：原有同屏 / ENet 权威会话，网络协议未重写。
- `scripts/ui/main.gd`：单一小游戏舞台、四周座位、底部操作与隐私遮挡。
- `scripts/ui/round_subtitles.gd`：独立字幕时钟与逐句淡入淡出，不推进规则。
- `scenes/main.tscn`：默认 8 人预览，或作为派对宿主子场景。
- `assets/art/`：原版月夜背景、角色插画与新增中性座位头像。几何主题已从活动源码移除，历史仍在 Git。

房主拥有完整规则，客户端只发意图；服务端以 RPC 实际发送者 ID 鉴权。每位玩家只收到自己的身份、允许的队友信息与记录。公共画面不显示查验记录；换人清空上一次目标选择。热座依赖玩家遵守交接约定，不是独立登录安全系统。ENet 未配置加密，可信朋友局域网原型不防房主读内存，不含公网服务或反作弊。
