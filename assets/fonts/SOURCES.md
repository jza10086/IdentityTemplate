# Font sources and licensing

- NotoSansSC-Regular.otf: Noto Sans CJK / Simplified Chinese UI face retained from the existing locally licensed asset set. Original project: https://github.com/notofonts/noto-cjk . SIL Open Font License 1.1; full distribution licensing is included in LICENSE.txt. Bundled for offline Chinese rendering.
- MoonveilSerif.otf: a renamed, subset derivative of Noto Serif CJK SC from the system Noto Serif CJK collection, same original project and SIL Open Font License 1.1. Retains U+0000–00FF, U+2000–206F, U+2600–26FF, U+3000–303F, U+4E00–9FFF, U+FF00–FFEF and required layout glyphs. Renamed Moonveil Serif. Other characters fall back to the complete bundled Noto Sans face. No font download is required.
